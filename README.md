# 898

> An unblocked website disguised as Humble ISD's student dashboard — with built-in proxy access.

---

## What is 898?

**898** is a stealth unblocked site built to look just like the Humble ISD student dashboard. It's designed to fly under the radar on school networks while giving students access to games, websites, and tools that would otherwise be blocked.

Whether you're on a Chromebook or any school-managed device, 898 blends in while giving you full access.

---

## Features

- 🎭 **Disguised UI** — Mimics the look and feel of the Humble ISD dashboard
- 🔓 **Proxy Access** — Built-in web proxy to bypass network restrictions
- ⚡ **Fast & Lightweight** — Minimal footprint, quick to load
- 🔒 **Stealth** — Designed to avoid detection on school networks
